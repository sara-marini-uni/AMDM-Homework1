# AMDM-Homework1
Solutions to Homework 1 exercises for the Algorithmic Methods of Data Mining course (Data Science Master's degree)
## Repository Structure
The repository is organized as follows:

* **`scripts.ipynb`**: A Jupyter Notebook containing the Python source code for all the completed exercises. The notebook is structured into two main sections:
  * **Problem 1**: Includes solutions categorized into 13 topic sections:
    1. Introduction
    2. Data Types
    3. Strings
    4. Sets
    5. Collections
    6. Date and Time
    7. Exceptions
    8. Built-ins
    9. Python Functionals
    10. Regex and Parsing Challenges
    11. XML
    12. Closures and Decorators
    13. NumPy
  * **Problem 2**: Contains solutions for 6 specific challenges.

* **`printouts/`**: A folder containing the PDF proof of submission for each challenge completed on HackerRank, organized into two subfolders:
  * `problem1/`: PDF submission printouts for all Problem 1 challenges.
  * `problem2/`: PDF submission printouts for all Problem 2 challenges.
